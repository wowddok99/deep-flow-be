# ADR-003. 세션 검색 색인은 Outbox로 후처리한다

## 상태

Accepted

## 배경

공유 세션은 크루 검색과 피드 기능에서 조회됩니다. 세션 공유, 공유 철회, 태그 변경은 DB 상태뿐 아니라 검색 인덱스에도 반영되어야 합니다.

공유 트랜잭션 안에서 외부 검색 엔진을 직접 호출하면 검색 엔진 장애가 세션 공유 실패로 이어질 수 있고, DB 커밋과 검색 색인 반영의 성공 여부가 엇갈릴 수 있습니다.

## 결정

세션 공유 관련 변경은 DB 트랜잭션 안에서 `OutboxEvent`로 저장하고, `OutboxWorker`와 `OutboxProcessor`가 검색 색인을 후처리합니다.

처리 대상 이벤트:
- `SESSION_SHARED`
- `SESSION_UNSHARED`
- `SESSION_TAGS_UPDATED`

## 결과

장점:
- 공유 저장과 후처리 요청 저장을 같은 트랜잭션으로 묶어 누락을 줄임
- 검색 엔진 장애가 사용자 요청 전체 실패로 번지는 것을 줄임
- 실패 이벤트를 retry 상태로 남겨 재처리할 수 있음
- Elasticsearch와 MySQL Fulltext 같은 검색 구현 변경이 유스케이스 흐름에 덜 영향을 줌

단점:
- DB 반영과 검색 결과 반영 사이에 짧은 지연이 생길 수 있음
- Outbox worker 운영 상태를 모니터링해야 함
- 재시도 한도 초과 이벤트를 어떻게 운영 처리할지 별도 정책이 필요함
